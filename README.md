# Product Manager

A product catalogue: a **.NET 10** REST API and an **Angular 22** web app.

## Requirements

- .NET SDK 10
- Node.js 20.19+
- SQL Server LocalDB (or Docker, see below)

## Run

```bash
# API - http://localhost:5186/swagger
cd backend/src/ProductManager.Api
dotnet run
```

```bash
# Web app - http://localhost:4200
cd frontend/product-manager-web
npm install
npm start
```

On first run the API creates the database with EF Core migrations and seeds sample data.

**No LocalDB?** Start SQL Server with `docker compose up -d` and set the connection string before
`dotnet run`:

```powershell
$env:ConnectionStrings__ProductManagerDatabase="Server=localhost,1433;Database=ProductManager;User Id=sa;Password=Your_strong_Passw0rd;TrustServerCertificate=True"
```

## Test

```bash
cd backend && dotnet test
cd frontend/product-manager-web && npm test
```

Integration tests need LocalDB. Without it they are skipped, not failed.

## Endpoints

| Method | Route |
| --- | --- |
| `GET` | `/api/products` |
| `POST` | `/api/products` |
| `GET` | `/api/products/{id}` |
| `PUT` | `/api/products/{id}` |
| `DELETE` | `/api/products/{id}` |
| `POST` | `/api/products/{id}/decrement-stock/{quantity}` |
| `POST` | `/api/products/{id}/add-to-stock/{quantity}` |
| `GET` | `/api/products/search?name={name}` |
| `GET` | `/api/products/stock-level?min={min}&max={max}` |

## Design notes

- **6-digit IDs:** generated by a SQL Server sequence (100000–999999), so they stay unique across
  any number of API instances.
- **Concurrency:** a `rowversion` column stops two requests from overwriting each other. Stock
  changes retry automatically; conflicting updates return `409`.
- **Deletes** are soft, so a product's stock history is kept.
- **Layers:** Domain → Application → Infrastructure (EF Core) → Api.
